# BookVerse 쇼핑몰 데모

## 실행
- `index.html`을 브라우저에서 열면 됩니다.
- GitHub Pages: 저장소 루트에 `index.html`과 `img/` 폴더를 올린 뒤 Settings → Pages에서 배포 브랜치와 `/ (root)`를 선택하세요.

## 포함 기능
- 반응형 온라인 서점 메인 화면
- 3종 히어로 슬라이드
- 상품 검색 및 장바구니
- 브라우저 로컬 저장 기반 데모 회원가입/로그인
- 일반/실버/골드/VIP 등급별 포인트 적립률 계산
- 데모 주문 및 전자책 내 서재 추가

## 실제 서비스 전환 시 필요한 작업
GitHub Pages는 정적 호스팅입니다. 실제 결제 승인, 보안 회원 인증, 주문/재고/배송 관리, 전자책 파일 보호 및 구매자 권한 검증은 서버가 필요합니다. PG사 결제 모듈과 백엔드/API, 데이터베이스, 전자책 뷰어를 연결해야 합니다.
